# Gryd — AI Video Editor Portfolio

Portfolio profesional de edición de video, dirección visual y producción con inteligencia artificial.

## Stack

- HTML semántico
- CSS responsive
- JavaScript sin dependencias
- Video HTML5

## Ejecutar localmente

Abrí `index.html` directamente o iniciá un servidor local desde esta carpeta:

```bash
python -m http.server 8000
```

Después visitá `http://localhost:8000`.
